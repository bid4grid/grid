1. Electric Power System Overview & Single Line Diagrams (SLD)

Single line diagrams (SLD) represent balanced 3-phase power networks using a single conductor line to depict all three phases. Component representations follow IEEE Std 315 and IEC 60617:

  • Synchronous Generator: Circle labeled with ‘G’ indicating source EMF $E_g \angle \delta$.
  • Power Transformer: Two interlocking circles or two parallel coiled windings indicating turns ratio $N_1:N_2$.
  • Circuit Breaker (CB): Square box representing interrupting device rated for subtransient fault current ($I_f''$).
  • Busbar: Heavy solid conductor line interconnecting generation, transmission, and load feeders.

2. Complex Power & Power Factor Correction

Complex power $\mathbf{S}$ in single-phase and balanced three-phase systems is defined as:

S = P + jQ = |S| ∠ θ = V · I*
|S| = √(P² + Q²)   [kVA / MVA],   cos θ = P / |S|   (Power Factor)

To correct power factor from $\cos\theta_1$ to a higher target $\cos\theta_2$ at constant active power $P$:

ΔQcap = P · [tan(arccos(pf1)) − tan(arccos(pf2))]   [kvar / MVAR]
C = ΔQcap / (ω · V²)   [Farads]

4. Synchronous Generators (P-δ Stability)

Synchronous machine steady-state excitation and power-angle characteristics:

Cylindrical (Round) Rotor:

Eg = Vt + Ia(Ra + jXs)
P(δ) = [ |Eg| |Vt| / Xs ] · sin(δ)
Pmax occurs at torque angle δ = 90°

Salient-Pole Machine (Blondel Two-Reaction Theory):

P(δ) = [ |Eg| |Vt| / Xd ] · sin(δ) + [ |Vt|² (Xd − Xq) / (2 Xd Xq) ] · sin(2δ)

The second term represents reluctance power resulting from rotor saliency ($X_d > X_q$), shifting peak power $P_{max}$ to $\delta < 90^\circ$.

5. Power Transformers

Parameters are derived from standard Open-Circuit (OC) and Short-Circuit (SC) test measurements:

Rc = Voc² / Poc,    Xm = Voc² / Qoc   (Shunt core branch)
Req = Psc / Isc²,    Xeq = √( (Vsc / Isc)² − Req² )   (Series winding branch)

Full-load efficiency ($\eta\%$) and exact Voltage Regulation (VR%):

η% = [ Pout / (Pout + Pcore + m² · Pcu,FL) ] × 100
VR% = [ (|V2,no-load| − |V2,rated|) / |V2,rated| ] × 100

6. Transmission Lines & ABCD Two-Port Parameters

Two-port matrix relationship: $[V_S; I_S] = [A, B; C, D] \cdot [V_R; I_R]$. By reciprocity, $AD - BC = 1$.

  • Short Line (< 80 km): $A=1, B=Z, C=0, D=1$.
  • Medium Line Nominal Π (80–250 km): $A = D = 1 + YZ/2, B = Z, C = Y(1 + YZ/4)$.
  • Long Line Distributed Hyperbolic (> 250 km):
    γ = √(z · y) = α + jβ,    Zc = √(z / y)
    A = D = cosh(γl),   B = Zc · sinh(γl),   C = (1 / Zc) · sinh(γl)

Ferranti Effect: At no load ($I_R = 0$), $V_{R,nl} = V_S / A$. Because $\cosh(\gamma l) < 1$ on low-loss capacitive lines, receiving voltage rises above sending voltage ($V_R > V_S$).

Surge Impedance Loading: $SIL = V_{LL}^2 / |Z_c|$ MW. Loading a line at SIL produces a flat voltage profile.

8. Power Flow (Gauss-Seidel)

Buses are categorized into Slack ($|V|, \delta$ fixed), PV Generator ($P, |V|$ fixed), and PQ Load ($P, Q$ fixed). Real and reactive power injections relate to the Bus Admittance Matrix $\mathbf{Y}_{bus}$:

Vi(k+1) = (1 / Yii) · [ (Pi − jQi) / (Vi(k))* − ∑j ≠ i Yij Vj ]

9. Fault Analysis & Fortescue Symmetrical Components

Unbalanced 3-phase phasors $[V_a, V_b, V_c]$ decompose into Zero, Positive, and Negative sequence components $[V_0, V_1, V_2]$ via operator $a = 1 \angle 120^\circ$:

Vabc = A · V012,    V012 = A−1 · Vabc
where A = [1, 1, 1; 1, a², a; 1, a, a²],   a = −0.5 + j(√3/2)
