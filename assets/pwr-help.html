1. Electric Power System Overview & Single Line Diagrams (SLD)

Single line diagrams (SLD) represent balanced 3-phase power networks using a single conductor line to depict all three phases. Component representations follow IEEE Std 315 and IEC 60617:

  • Synchronous Generator: Circle labeled with ‘G’ indicating source EMF Eg ∠ δ.
  • Power Transformer: Two interlocking circles or two parallel coiled windings indicating turns ratio N1:N2.
  • Circuit Breaker (CB): Square box representing interrupting device rated for subtransient fault current (If″).
  • Busbar: Heavy solid conductor line interconnecting generation, transmission, and load feeders.

2. Complex Power & Power Factor Correction

Complex power S in single-phase and balanced three-phase systems is defined as:

S = P + jQ = |S| ∠ θ = V · I* |S| = √(P2 + Q2) cos θ = P|S| (Power Factor)

To correct power factor from cos θ1 to a higher target cos θ2 at constant active power P:

ΔQcap = P · [tan(cos−1(pf1)) − tan(cos−1(pf2))] [kvar / Mvar]
C = ΔQcapωV2 [Farads]

4. Synchronous Generators (P-δ Stability)

Synchronous machine steady-state excitation and power-angle characteristics:

Cylindrical (Round) Rotor:

Eg = Vt + Ia(Ra + jXs)
P(δ) = |Eg| |Vt|Xs sin(δ)
Pmax occurs at torque angle δ = 90°

Salient-Pole Machine (Blondel Two-Reaction Theory):

P(δ) = |Eg| |Vt|Xd sin(δ) + |Vt|2(Xd − Xq)2XdXq sin(2δ)

The second term represents reluctance power resulting from rotor saliency (Xd > Xq), shifting peak power Pmax to δ < 90°.

6. Transmission Lines & ABCD Two-Port Parameters

Two-port matrix relationship: [VS; IS] = [A, B; C, D] · [VR; IR]. By reciprocity, AD − BC = 1.

  • Short Line (< 80 km): A = 1, B = Z, C = 0, D = 1.
  • Medium Line Nominal Π (80–250 km): A = D = 1 + YZ/2, B = Z, C = Y(1 + YZ/4).
  • Long Line Distributed Hyperbolic (> 250 km):
    γ = √(zy) = α + jβZc = √(z/y)
    A = D = cosh(γl)B = Zc sinh(γl)C = 1Zc sinh(γl)

Ferranti Effect: At no load (IR = 0), VR,nl = VS/A. Because cosh(γl) < 1 on low-loss capacitive lines, receiving voltage rises above sending voltage (VR > VS).

Surge Impedance Loading: SIL = VLL2/|Zc| MW. Loading a line at SIL produces a flat voltage profile.
